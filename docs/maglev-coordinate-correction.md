기관·노선·역 번호·역명·좌표쌍이 위 원문과 모두 일치할 때만 typed 위경도를 교환한다.
`raw` 원문은 불변이다. 원본에서 정정된 정상 좌표는 그대로 통과하며, 다른 역이나 새로운
잘못된 좌표는 기존처럼 두 좌표를 `None`으로 반환한다. API `mapCordX/mapCordY`에는 적용하지 않는다.
