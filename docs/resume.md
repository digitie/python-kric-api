
## 2026-11-09 — KRIC 일반철도·KTX 공개 목록

## 2026-11-02 — KRIC와 공식 웹의 연장 구간 코드 차이

## 2026-11-02 — 시간표 행선지 범례

부산 3·4호선 등의 일부 방향은 출발 span의 접근성 글자를 `행22분 출발`처럼 반환하고 행선지는 같은 페이지의 course-mark 범례에만 제공한다. 정확한 course-mark 번호가 같은 유일한 범례 이름을 읽고, 해당 페이지 역 선택지에서 이름이 유일하게 일치할 때만 종점 코드를 연결한다. 방향 순서·인접역·임의 이름 매핑은 쓰지 않는다. 범례 부재·충돌·잘못된 시각과 다중 course 번호는 오류로 남긴다.

실제 망미·고촌의 양방향 네 원문에서 세 요일과 종점 코드 연결을 확인했다. WSL254개 통과·live2개 제외·커버리지93.15%(해당 모듈100%)·mypy 통과다. parser_revision을20261102-course-legend로 갱신하며 소비자가 구 파서 실패만 한 번 복구한다. 실제 운영 저장 수용은 소비자 배포에서 확인한다.

## 2026-11-01 부산교통공사 공식 시간표

async with HumetroClient() as client:

한 방향의 평일(8)·토요일(7)·일/공휴일(9)을 반환한다. 선택 역·노선·방향·요일 열과 시간표 구조를 검증하며 형식 오류를 정상 빈 결과로 바꾸지 않는다. 분 단위 출발 계획만 제공하며 열차 번호·도착 시각·서비스 날짜·실시간 도착은 추정하지 않는다. 원문의 23시 뒤 00:24는 `departure_time="24:24"`, `source_clock="00:24"`로 보존한다. 행선지 코드는 같은 페이지의 역 목록에서 이름이 유일하게 일치할 때만 제공한다. 응답 SHA-256과 원천 URL을 반환하며 수집 주기·양방향 원자 저장·실패 후 정상본 보존은 소비자 책임이다.
